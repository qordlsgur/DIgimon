# Digimon Super Rumble 모작

**장르:** 턴제 RPG  
**개발 인원:** 1인 개발  
**개발 기간:** 2025.08 ~ 2025.10  
**플랫폼:** PC (Windows)  

**Language:** C++  
**Graphics:** DirectX 11  
**IDE:** Visual Studio 2022  

## 담당 역할
1. 전체 시스템 단독 개발
2. 전투 로직 및 턴 관리 구현
3. 캐릭터 스킬 및 이펙트 구현
4. DirectX11 기반 3D 렌더링
5. UI 시스템 구현

## 핵심 기능
1. 턴제 전투 흐름 (대기 -> 선택 -> 실행 -> 종료)
2. 전투 흐름 UI
3. State Pattern 기반 FSM을 이용한 캐릭터 상태 관리

## 문제 해결
1. 턴제 전투 시스템 설계
2. 애니메이션 상태 머신으로 관리

## 프로젝트 소개
디지몬 슈퍼럼블을 기반으로 한 턴제 RPG 게임 모작 프로젝트입니다.  
기본 조작, 디지몬 스킬 및 이펙트를 C++ / DirectX 11을 이용하여 3D 그래픽과 UI로 구현했습니다.
